# HOSA — Highway Old Students' Association

A responsive web application for former students of Highway Secondary School (Kiganda, Kassanda District, Uganda).

**Live site:** <https://hosa-website-vhts.onrender.com>

**Trello board:** <https://trello.com/b/iRLK5T7/hosa-final-project>

## Tech Stack

- HTML5, CSS3, Vanilla JavaScript (ES Modules)
- Vite (build tool)
- Two external APIs: REST Countries + Nominatim (OpenStreetMap)
- Deployed on Render
